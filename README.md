# Daily Learnings

A personal repository documenting my learning journey in Computer Science and
Artificial Intelligence & Machine Learning.

This repository contains notes, visual explanations, experiments, and
references created while studying different concepts. It is intended to
document the learning process rather than present only polished or completed
work.

## Contents

### Calculus

Mathematical foundations being studied as part of my Computer Science and
AI/ML learning.

Topics currently include:

- Limits and continuity
- Derivatives
- Geometric interpretation of derivatives
- Derivative rules and formulas
- Trigonometric derivatives
- Mathematical intuition and visual explanations
- Worked examples and derivations

## Tools

The repository is maintained using:

- Obsidian for note-taking and knowledge management
- Excalidraw for diagrams and visual explanations
- Markdown for storing notes
- Git and GitHub for version control and maintaining the learning archive

Selected Obsidian Community Plugins are also used where they are useful for
organizing and creating the notes.

## Learning Approach

The purpose of this repository is to understand concepts rather than simply
collect notes or memorize information.

The general approach is:

Learn → Understand → Explain → Practice → Revisit

The notes may change over time as my understanding improves. Older
explanations may be corrected, expanded, or replaced.
